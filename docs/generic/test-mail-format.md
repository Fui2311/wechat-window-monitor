# 测试发信通道的邮件模板

`wechat_monitor.mail_format.format_match_mail` 输出主题、纯文本及 HTML 三部分，供独立测试发信通道传给 `send_email(..., html_body=html)`。这不代表 Dashboard 已有完整 SMTP 配置与发送模块。

- 单栏卡片布局：会话、发送者、发送时间、采集时间，随后是判断依据和消息原文；原文命中片段高亮。
- `sent_at` 仅来自原消息数据，缺失显示“未读取”；不以 observed_at / received_at 冒充发送时间。转发子消息有独立时间时另列展示。
- 所有有效时间转换为北京时间（UTC+8）。无时区或无效时间标明待核对。
- 采集时间来自 observed_at，缺失时采用 received_at。它表示本机发现消息的时间。
- HTML 转义来源名称、正文、依据、证据和发送者；不加载外部资源。纯文本邮件客户端可读取同样的信息。
- 发送使用 MIME text/plain + text/html 两种版本；SMTP 接受不等于已验证收件箱送达或所有邮件客户端的显示效果。

2026-11-02 验证：时间区分、子消息时间、时区转换、HTML 注入转义测试通过；新版相关回归25项通过。HTML 在320、390、1280像素视口进行宽度检查。截图接口超时，不计为截图视觉验收；向已配置邮箱发送了一封明确标注“排版预览”的实际邮件，供邮件客户端核对。
