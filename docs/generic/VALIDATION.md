339项Python回归通过（macOS跳过2项Windows DPAPI旧兼容测试），其中19项覆盖新的通用产品。35项旧前端回归和4项新HTTP/状态/原文/开发代理契约通过。ruff、版本同步、前端格式检查与生产构建通过。

wheel在仓库外新虚拟环境安装，确认从site-packages导入：合成离线示例重复创建不增加窗口或规则；JSONL实际捕获、本地识别生成一条匹配；生产HTML及两个hash资源可请求；规则/记录/工作空间API正常；sdist可重建wheel。安装冒烟对真实桌面、模型和SMTP使用拒绝替身，所有数据位于临时根和假用户目录。

两个实际运行的CLI尝试使用相同数据目录时，第二实例被OS锁拒绝；文件留存不会被当作活跃进程证据。独立App在本机编译、签名，self-test报告2.0.0/arm64/ok=true，不触发权限授权、真实捕获或凭据读取。旧讲座安装器在本产品元数据下拒绝执行，避免误部署旧服务。

## 浏览器真实使用流程

源码生产资源、本地假模型HTTP和JSONL合成文件完成：创建项目小助手 -> 窗口设置 -> 生成本地草稿 -> 本地试测 -> 启用 -> 运行 -> 原文匹配记录。模型调用计数保持1，后续采样不增加调用。

再从下拉底部新增状态通知窗口，选择语义模式 -> 保存 -> 生成 -> 语义试测 -> 启用 -> 运行 -> 查看规则关联的匹配记录。两个窗口累计模型调用为2次生成、2次识别（一次手动试测、一次新消息），重复采样没有额外调用。停止语义窗口后，下拉中本地窗口green、语义窗口gray，状态与各自记录隔离。

独立wheel启动的真实浏览器确认：重启默认停止；离线Demo开始后出现匹配；运行中窗口配置控件禁用。开发用Vite路径先实际复现同源拒绝，再修正代理对同源localhost请求的头部转换，浏览器GET状态与POST创建均通过；外部来源保留原头并被后端拒绝。

截图使用纯合成数据，见assets/dashboard.png。本机细节日志保存在忽略的state/generic-audit，不随仓库上传。
