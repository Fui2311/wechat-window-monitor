# 转发卡片正文读取

新版原先只调用原生快照，没有调用旧版展开适配器，外层预览会以普通消息完成识别。本次补上显式展开流程，并阻止未读取正文的转发标题参与识别。

## 使用

在窗口设置启用“自动打开转发卡片并读取正文”。macOS需要选择卡片位置：自己转发通常在右侧，他人发来的卡片通常在左侧。设置只在停止监控后保存，之后启动监控。

只对新入库或明确重试的转发卡片操作。macOS先验证精确窗口，重新采样绑定卡片，再使用旧版带5秒提示的 activate_click 适配器；空闲时打开、读取并返回。用户移动鼠标或中止提示可取消。该流程会短暂切到微信，不是完全后台无焦点操作。

读到的 children 保存到原始消息记录，同时保留原卡片指纹，避免后续采样重复识别。识别输入排除外层标题和未展开的嵌套卡片预览；失败保留原文并明确标记错误。模型失败后重试复用已读取正文，无需再次点击。

旧的标题记录不会自动重放。消息记录页会标注“正文尚未读取”；需要补读时，点击该条“读取转发正文”，仅将这条记录重新排队，按当前规则识别。操作可能产生新的匹配提醒，需核对对应窗口与发送范围。

页面逐条展示读取到的内部消息、发送者与实际可用的时间。测试发信模板也按子消息分条显示；没有实际时间时不推测。
