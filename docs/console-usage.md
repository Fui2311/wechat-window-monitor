# 控制台使用流程与操作范围

## 首次使用

1. 使用独立配置和数据目录，填写微信中完整、精确的群名。
2. 打开目标群独立窗口，先运行窗口探针。探针成功只代表本次窗口可读。
3. 启动监控（预览），到「采集消息」核对真实采集时间、发送者与原文，再到「讲座消息」核对识别结果、报名信息及邮件预览。
4. 若需要邮箱通知，进入「配置与邮箱设置」。未配置时页面提供对应配置文件的本机设置命令；Windows 在 PowerShell 执行，macOS 在终端执行。`email setup` 会要求隐藏输入授权码，并实际发送一封测试邮件。
5. 配置完成后刷新。macOS 凭据授权失效时使用「授权邮箱」；Windows 使用「检查邮箱」，检查本机 DPAPI / 环境变量。检查和授权操作本身均不发送测试邮件。Linux 仅支持环境变量凭据，页面列出所需变量名称。
6. 点击「发信模式启动」，先核对管理群、已有待发送记录数、最早计划时间及重试数，再确认是否启用真实 SMTP。符合当前规则的旧积压可能立即发送；新任务仍可能在确认期间增加。已停止重试的失败任务不会自动重发。

## 查看记录和管理服务

数据源下拉框用于查看当前群、其他服务、历史库或 Demo。页面持续显示当前查看的数据源和管理群，避免把历史内容当成当前服务状态。选择历史库不会切换监控群。点击「返回当前群」恢复当前活动库。手动刷新会先同步管理状态与数据源清单，再读取记录，因此能发现打开页面后新增的历史库；同一管理群内主动选择的历史库和未保存处理草稿会保留，刷新期间重复点击合并为一次。

监控启停、重启、处理配置、邮箱操作、运行日志和「预览到期任务」始终作用于当前管理群；日历导出、讲座原文、采集消息、邮件队列及邮件正文预览作用于所选数据源。多服务列表中的停止按钮作用于该行明确标记的服务。

切换监控群需要在配置页输入精确群名、探测后确认。旧群历史保留，新的活动库会被选中并记住；刷新不会自动退回上一个群。切换后的监控保持停止状态，先手动启动预览。其他页面切群后，本页手动刷新或完成启停操作会同步新的活动库；未编辑的目标群输入随之更新，已编辑的目标群草稿保留。停止确认会展示并绑定当时的管理群，若确认期间群发生变更，后台拒绝该请求并要求重新核对。

切换数据源时旧内容立即清空，旧请求的迟到响应不会覆盖新库内容；对应邮件预览会关闭。读取失败会标明错误，保留同一数据源上次成功读取的内容时也会提示。接口恢复后，即使记录未变化，服务列表和空讲座列表也会重新显示成功结果。空讲座提示会区分搜索、历史只读、演示和当前群；历史空库不会暗示切换了监控群。

网页日历仅导出所选数据源中活动时间明确的记录，先检查响应再请求浏览器下载。没有可导出项目时会说明原因，不下载空文件；失败时可重试。导出期间切库或关闭控制台会丢弃迟到结果，避免保存旧数据源文件。保存位置由浏览器决定。

页头和服务列表使用一致的监控状态：进程启动或存活不等于已成功采集；仅明确采集中的服务标为监控中。状态读取失败时需检查后台和配置，不能据此判断监控已经停止。

## 处理配置和共享来源

本机规则无需模型接口，默认收起「可选：LLM 接口配置与测试」。可用鼠标或键盘展开；展开本身不会切换模式或访问模型。当前使用 LLM 或点击「LLM 提取」时会展开参数，后续刷新保留手动折叠状态和未保存草稿。LLM 参数保存后用于后续新消息；密钥留空保留已保存值，勾选清除才删除本机密钥文件。保存或测试期间表单暂时锁定，避免较早的响应覆盖新的输入。修改表单后页面标记未保存；立即切回规则时会保留其他未保存草稿，并明确提示。

使用 `processing_config_path` 引用共享配置时，页面显示实际来源并保持只读。请使用来源配置启动控制台进行管理，例如：

```bash
wechat-track --config /path/to/source.toml web --port 8765
```

修改共享来源会影响所有引用它的服务后续的新消息。跟随配置页面的测试使用共享参数及密钥，只处理手动输入的测试原文；不会保存设置、入库或发邮件。测试会访问所配置的模型接口，可能产生模型费用。

界面的活动时间、采集时间和服务时刻按配置时区显示，当前项目仅支持 `Asia/Shanghai`；浏览器位于其他时区也不会改变讲座的北京时间。

## 演示、预览和键盘操作

「运行 Demo 回放测试」写入隔离的 `demo.sqlite3`，运行后自动进入演示结果。演示任务固定显示「演示预览，不会发送」，不会因为启动当前服务而投递，也不计入真实待发数量。Demo 仍可预览邮件正文和原始样例。

「预览到期任务」评估当前管理群的到期任务并展示队列，不发送邮件。它不同于命令行显式的 `tick --send`。默认使用预览，真实发信需单独启用。

窄窗口中的导航标签保持横排；可在导航条内水平滚动或用 Tab 聚焦对应按钮后按 Enter 切页。

弹窗支持键盘：打开后焦点进入弹窗，Tab / Shift+Tab 在弹窗内循环，Esc 关闭当前弹窗并返回打开它的控件。确认弹窗默认聚焦「取消」。从讲座详情打开邮件预览后，关闭预览会保留详情。

SMTP 接受表示邮件服务器已收到提交，不保证已经进入收件箱。探针、进程存活和成功采样各自代表不同状态；完整历史、微信登录与桌面条件仍需实际核对。
