# 1.1.0 前端边界与版本工程验收

## 模块与行为契约

- `presentation.js` 独立接收数据和时区，不读取 DOM、本机存储、网络或控制器状态；独立验证日期、原始时间、HTML 转义、报名链接协议和状态标签。
- `http.js` 接收请求函数，统一 JSON GET/POST 与文本响应；独立验证序列化、JSON/文本/空错误及网络异常。模块加载不发请求。
- `app.js` 通过明确接口调用以上模块，保留页面状态、请求序号、草稿和 DOM 控制。原有 29 项行为回归不再覆盖内部 API 函数，而是通过真实适配器注入假 fetch。
- 静态资源仅允许明确的文件名；Python HTTP 回归核对两个新增脚本可读取、MIME 正确且先于控制器加载，未列入白名单的脚本仍返回 404。

版本以 `pyproject.toml` 为唯一来源。同步脚本默认只读，显式 `--write` 才更新当前组件和文档标签；先校验全部目标再写入。临时副本验证了漂移检查不写文件、同步后标签一致、历史记录不变，以及缺少目标字段时不发生部分写入。CI 与安装包冒烟执行只读版本检查。
