# 1.0.4 导航与可选模型设置验收

本轮只修改控制台布局与设置区域展示，不修改 Python 业务或数据库格式。使用独立临时配置、合成消息及 localhost 假模型，未升级常驻监控，未发 SMTP 或微信。

## 窄窗口导航

实际浏览器宽度为 495px。修复前按钮最高 145.5px，导航高度 155.5px，标签逐字竖排。修复后所有按钮均为 34.5px，导航高度 44.5px；标签保持横排，超宽内容在导航条内滚动，页面文档宽度仍为 495px。配置页按钮可正常切换并滚入可见区域。

曾尝试四个临时视口设置，但当前浏览器实际读取始终是 495px，因此不将这些尝试记为四种宽度的验收。临时覆盖已重置。更宽和更窄窗口仍需相应真实浏览器布局验证。

## 可选 LLM 设置

- 本地规则初次打开默认收起可选参数，鼠标或 Enter 可展开，展开本身不保存或调用模型。
- 展开后修改模型名，手动刷新后草稿及展开状态保留。点击 LLM 模式会展开参数并保持原有保存语义；用户在 LLM 模式手动收起后，后续刷新尊重该选择。
- 嵌套提取测试可正常调用 localhost 假模型并显示结果；测试前后 messages、events、outbox 数量均为 1，未入库或排队。
- 1.0.4 wheel 独立安装后的控制台导入路径位于其虚拟环境 site-packages。共享 LLM 配置首次自动展开，模型和保存按钮禁用，来源说明可见；共享测试成功，手动收起再刷新仍保持收起和只读。

20 项 Node 状态回归及 JavaScript 语法、ruff、差异空白检查通过；新增回归覆盖首次模式、手动展开/收起、刷新保留草稿和共享只读。wheel 仓库外 CLI/API 冒烟、sdist 重建及 Mac ZIP 的 CRC、80 个清单文件 SHA256、文档链接检查通过。跨平台 Python 测试和原生编译以对应 GitHub CI 为准，不将本轮 UI 检查等同于桌面采集和邮箱送达验收。
