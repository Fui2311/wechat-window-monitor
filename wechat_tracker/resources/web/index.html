💡 微信接入核查指南 (Mac / Windows)

  • 微信登录：微信客户端必须保持已登录状态。
  • 独立窗口：在微信聊天列表中双击或右键将当前监控的目标微信群打开为独立窗口。
  • 非最小化：独立群窗口必须处于可见/非最小化状态（可以被其他窗口遮挡，但不可最小化到 Dock 或托盘）。
  • macOS 辅助功能权限：在「系统设置」→「隐私与安全性」→「辅助功能」中允许 WeChat Lecture Tracker Capture.app 及运行终端。
  • 自动展开合并转发：支持对群内已验证的合并转发卡片进行安全展开与解析，未展开时保留待补全状态。
通知内容处理 本地规则

本地规则在本机识别；LLM 模式将新消息正文和附件名称发送至下方接口，提取标题、摘要、活动及报名信息。相关通知保留原文，接口失败时回退本地规则。切换仅对新消息生效。

校区规则（本地规则与 LLM 共用）：仅提醒石牌校区／石牌校园；大学城、佛山／南海及其他明确校区不提醒。未提及校区仍可通知，不按教学楼名推测；以实际举办地点为准，主讲履历或报名对象中的校区不作为举办地点。多地点包含石牌会场时可提醒。

邮件格式随处理方式切换：本地规则发送原文；LLM 展示提取信息并附原文。

配置持续保存，适用于后续所有新消息；各服务的处理设置来源见下方服务列表。数据源切换仅查看对应群的记录。
